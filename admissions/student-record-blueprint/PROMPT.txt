나는 고등학교 담임교사이고, 학생부종합전형을 준비하는 3학년 학생들을 위한
학습지를 제작 중이다. 이전 세션에서 학습지의 4면 구성을 모두 확정했고,
이번 세션에서는 대학에서 공식 발표한 학생부종합전형 가이드북을 제공할 테니,
이를 분석하여 학습지 구성을 보완하고 HTML로 제작해달라.

─────────────────────────────────
【확정된 학습지 기본 설계】

형식: B4 2장, 총 4면 / HTML + Tailwind CSS
인쇄: B4 기준, A4도 지원 / CSS 강제 페이지브레이크 / 글씨 text-base 이상
핵심 원칙:
  - (2,3) 나란히 펼침 = 내 과거 생기부 vs 선배 사례 비교
  - (2,4) 나란히 펼침 = 내 과거 생기부 → 3학년 계획으로 발전
  - 2면·3면은 표 구조 동일 / 4면은 2면의 미래형

─────────────────────────────────
【1면 — 학종 준비 점검 + 안내】
Sheet 1 앞면. 학생이 직접 채우는 기본 점검지.

① 학종 3대 평가 역량 (체크표)
   - □ 학업역량: 지적 호기심, 탐구력, 학습 태도 → 교과 세특
   - □ 진로역량: 전공 관련 관심·활동의 일관성 → 세특·동아리·진로
   - □ 공동체역량: 협업, 리더십, 나눔과 배려 → 동아리·자율활동

② 대입 반영 항목 확인 (표)
   반영: 교과세특, 자율활동, 동아리(정규), 진로활동, 행동특성및종합의견
   미반영: 수상경력, 독서활동, 개인봉사, 자율동아리

③ 이수권장과목 점검 (5~6행 표)
   | 과목명 | □이수 □미이수 | 비고 |
   → 각 대학 모집요강에서 검색 후 기입

④ 시작 전 체크리스트
   □ 1·2학년 생기부 열어두었다
   □ 희망 학과 1개로 좁혔다 (자율전공 가능)
   □ 이수권장과목 정리했다
   □ 선배 사례집 또는 QR 준비했다

⑤ 사용 절차 STEP 1~6
   STEP1: 2면 - 내 생기부 정리 및 핵심 스토리 뽑기
   STEP2: 3면 - 선배 사례 최대한 많이 찾아 정리
   STEP3: 2면+3면 나란히 펼쳐 비교
   STEP4: 4면 - 3학년 활동 계획 및 스토리 설계
   STEP5: 2면+4면 나란히 펼쳐 흐름 점검
   STEP6: 4면 하단 한 문장 완성

⑥ "나는 ___학생이다" 예시 문장 5개 (박스)
   - 나는 생명과학과 화학을 융합하여 환경 문제를 탐구하고,
     지속 가능한 해결책을 고민해온 학생이다.
   - 나는 수학적 사고를 사회 현상 분석에 적용하며,
     팀원들과 함께 문제를 해결해온 학생이다.
   - 나는 관심 분야를 중심으로 교과 간 경계를 넘나드는
     융합적 탐구를 꾸준히 이어온 학생이다.
   - 나는 진로 목표를 바탕으로 교과·동아리·자율활동 모두에서
     일관된 성장 스토리를 만들어온 학생이다.
   - 나는 공동체 안에서 리더십과 배려를 실천하며
     학문적 탐구와 인성을 함께 성장시켜온 학생이다.

⑦ QR코드 3개: 선배 생기부 검색 / 탐구 주제 참고 / 이수권장과목 확인

─────────────────────────────────
【2면 — 나의 과거 생기부 스토리 뽑기】
Sheet 1 뒷면. (2,3) 또는 (2,4) 조합의 왼쪽.

희망 학과: □ 특정 학과: ___ □ 자율전공

① 활동 개요 (최대 5개, 키워드 중심)
   | 구분 | 활동명/교과 | 키워드 |
   (교과세특×2, 동아리, 자율활동, 진로활동)
   각주: 면접에서 학과 무관 교과 개념도 질문될 수 있음

② 핵심 활동 스토리 (1~2개)
   활동명/교과: ___
   동기: 왜 이 활동을 하게 되었나?
   과정: 무엇을 탐구하거나 경험했나?
   난관: 어떤 어려움이 있었나? 어떻게 극복했나?
   성장: 이 활동 후 무엇이 달라졌나?

─────────────────────────────────
【3면 — 선배 사례 조사 (양적 나열)】
Sheet 2 앞면. (2,3) 조합의 오른쪽.
상단 안내: "← 2면과 이 면을 나란히 펼쳐 비교하세요"

선배 정보: 학과___ / 대학___ / 출처: □사례집 □QR □기타

선배의 활동 목록 (최대한 많이, 10행 이상)
   | 구분 | 활동명/교과 | 탐구주제/키워드 |
   (교과세특×5, 동아리×2, 자율×1, 진로×2)

이 선배가 드러낸 역량 체크:
□학업역량 □진로역량 □공동체역량 □자기주도성
□문제해결력 □융합적사고 □리더십

2면과 비교했을 때 내게 아직 없는 활동이나 주제: ___

QR코드 2개: 선배 생기부 검색 / 탐구 주제 참고

─────────────────────────────────
【4면 — 3학년 활동 스토리 설계】
Sheet 2 뒷면. (2,4) 조합의 오른쪽.
상단 안내: "← 2면과 이 면을 나란히 펼쳐 1·2학년 활동을 어떻게 심화할지 설계하세요"

① 활동 계획 개요 (표)
   | 구분 | 계획 활동명/교과 | 연결할 1·2학년 활동 |
   (교과세특×2, 동아리, 자율활동, 진로활동, 공동체역량드러낼활동)

② 핵심 활동 스토리 설계 (1~2개)
   활동명/교과: ___
   동기: 왜 이 활동을 3학년에 할 것인가? (1·2학년과의 연결고리)
   과정: 어떻게 탐구하거나 경험할 것인가?
   목표: 이 활동을 통해 무엇을 보여줄 것인가?

③ 나를 한 문장으로 (강조 마무리)
   "나는 ___________________________ 학생이다."

─────────────────────────────────
【이번 세션 작업 목표】

1. 위에 첨부하는 대학 학생부종합전형 가이드북(PDF 또는 텍스트)을 분석하라.
2. 가이드북을 바탕으로 학습지 4면의 구성·문구·예시 문장을 보완할 점을
   항목별로 제안하라.
3. 보완 내용을 반영하여 최종 확정된 구조를 보고하고,
   내 승인 후 HTML 코딩을 시작하라.

─────────────────────────────────
【기술 요구사항】

- 용지: @page { size: B4 portrait; } 기본
        A4 전환은 별도 클래스 토글 또는 미디어쿼리로 지원
- 여백: @page { margin: 8mm; } — 인쇄 시 잘리지 않을 최소한,
        최대한 좁게 설정. 내용이 용지를 꽉 채워야 함
- 페이지브레이크: 각 면 사이 CSS page-break-after: always 강제
- 글씨 크기: Tailwind 기준 본문 text-base(16px) 이상,
             섹션 제목 text-lg~text-xl, 표 내부도 text-sm 최소화
- 푸터: 각 면 하단에 페이지 번호 표시 (1/4, 2/4, 3/4, 4/4)
        CSS @counter 또는 하드코딩으로 처리
- 쓰기 공간: min-height 충분히 확보, 밑줄 또는 점선으로 표시
- 단일 HTML 파일로 완성 (CSS, JS 모두 인라인)
