### 비영리(NC)의 범위 — 저작권자의 해석

판단 기준은 **「돈이 오갔는가」가 아니라 「누가 주관하는가」**입니다.
학교·교육청·교육연수원·교과연구회 등 **공공·비영리 교육기관이 주관하는 교육**이라면,
**학생이 수강료를 내거나 강사가 강사료를 받더라도 비영리로 봅니다.**
공교육 교사가 운영하는 방과후학교, 교육기관이 주최하는 교원 연수가 여기 해당합니다.
반대로 **학원 등 영리 사업자가 주관하면 장소가 학교이고 수강료가 같더라도 비영리가 아닙니다.**

판단이 서지 않으면 [이슈](https://github.com/itmir913/printables/issues)로 물어봐 주십시오.
